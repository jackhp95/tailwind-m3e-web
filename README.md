# tailwindcss-m3e

Tailwind v4 plugin exposing [Material 3 Expressive](https://m3.material.io) design tokens and [@m3e/web](https://github.com/matraic/m3e) component CSS variables as Tailwind utilities.

**Status:** Pre-release. API will stabilise at v0.1.0.
